# 計算結果｜種数2・3ファイバー結び目の数体類数一覧

## 1. 目的と対象

`Alexander_poly_and_monodromy_of_fibered_knots_upto_13_crossings(1).csv` に収録されたファイバー結び目のうち、種数2および種数3で、Alexander 多項式が有理数体上既約なものを対象とする。

同じ Alexander 多項式をもつ結び目は1行にまとめた。根を `alpha` とし、対応する数体を `K = QQ(alpha)`、最大整環を `O_K`、べき整環を `R = ZZ[alpha]` とする。

表中の `index` は `[O_K:R]` である。類数と類群は最大整環 `O_K` に対するものであり、非極大整環 `R` の ideal-class monoid ではない。

## 2. 計算方法

- PARI/GP 2.17.2 の `polisirreducible` で既約性を判定した。
- `nfdisc` で体の判別式を求めた。
- 多項式判別式との比から `[O_K:R]` を求めた。
- `bnfinit(f,1)` で類数・類群を計算した。
- 全対象について `bnfcertify` が成功したため、類数・類群の結果は GRH に依存しない。

計算日：2026-08-29

## 3. Yang の判定への注意

`index = 1` なら `R = O_K` である。この場合、類数1なら任意の非零分数 `R`-ideal は単項である。

一方、`index > 1` では、体の類数が1でも `R`-ideal の単項性・可逆性は自動的には従わない。Yang の固有ベクトルから得られる `R`-ideal について、colon ideal、multiplier ring、または `R` の ideal-class monoid を直接調べる必要がある。
