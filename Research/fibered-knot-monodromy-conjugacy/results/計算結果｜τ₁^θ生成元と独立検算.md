# 計算結果｜τ₁^θ 生成元と独立検算

## 1. 独立検算の二つのルート

### Route A

Dehn twist formula

\[
\tau_1^\theta(t_c)=-|c|\wedge\ell_2^\theta(c)
\]

と cocycle の合成公式を使う。

### Route B

`DehnTwist`, `MappingClass`, `tau1_theta` を使わず、自由群の生成元像を直接入力する。

指数和と \(\ell_2^\theta\) を語の一文字ずつの計算から求め、

\[
\ell_2^\theta(\phi(g))
\]

から \(\tau_1^\theta(\phi)\) を復元する。

## 2. t_a

Route A / Route B は一致し、

\[
\tau_1^\theta(t_a)=0.
\]

→ 1.3a 完了。

## 3. t_b

Route A / Route B は一致し、

\[
\tau_1^\theta(t_b)
=
-\frac12X\wedge Y\wedge W
+\frac12Y\wedge Z\wedge W.
\]

→ 1.3b 完了。

## 4. twist 単体の非零性

非零：

\[
\tau_1^\theta(t_b),\quad
\tau_1^\theta(t_e).
\]

零：

\[
\tau_1^\theta(t_a),\quad
\tau_1^\theta(t_c),\quad
\tau_1^\theta(t_d),\quad
\tau_1^\theta(t_f).
\]
